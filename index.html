Questions people actually ask

What's the difference between Markstone and Vistaar?

Markstone is a one-time guided system: a 20-question quiz that produces a complete visual identity — palette, type, logo direction, and export-ready files. Vistaar is an ongoing toolkit for the content work that comes after — writing, LinkedIn carousels, a content queue, and course building, tuned to your niche.

Do I need both Markstone and Vistaar?

No. Many people start with Markstone to get the identity system, then use Vistaar afterward for ongoing content — but each works fine on its own if that's all you need.

Are the tools on this homepage free?

Yes. Palette Spark, Pair My Type, and Brand Match all run in your browser at no cost and don't require an account.

Which one should I start with?

If you don't have a brand system yet, start with Markstone. If you already have one and need help producing content around it, start with Vistaar. The Brand Match tool above can help you decide in under a minute.

Can I export what I build?

Yes. Markstone exports CSS variables, Adobe swatches, a Figma file, and a PDF brand guide. Vistaar's carousel tool exports PNG slides you can post directly.

Do you offer human designer help?

Markstone's Designer Collab and Done-For-You plans pair the quiz output with a real designer's review — see Markstone's pricing for details.
