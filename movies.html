Questions people actually ask

Does the writing assistant need an API key or internet connection?

No. It runs entirely inside this page using niche-tuned templates and your input — no account, no API key, no external service. Open the file and it works.

Where do my scheduled posts and courses get saved?

They're saved in this browser's local storage automatically as you add them, so they're still there next time you open this file on the same device and browser. Clearing your browser data will clear them too.

Does the content queue actually publish to LinkedIn or Instagram?

Not yet — direct publishing needs each platform's own connected account, which isn't wired up in this preview. The queue keeps your captions and dates organized so you can copy them across when you're ready to post.

Can I download the carousel slides as real images?

Yes — each slide renders as a real PNG you can download individually or all at once, sized for a LinkedIn carousel post.

Is billing live?

Not yet. The pricing section above is a preview of what's coming — every button there is intentionally inactive for now.

Can I customize the carousel colors?

Yes — use the color picker in the carousel preview section to change the slide background and text colors to match your brand while keeping the theme intact.
